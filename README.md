# HouseHub

## Project Description
A web platform where house/room owners can post rental listings, and tenants can search, filter, and request listings that match their needs.

## Features
Owner & Tenant registration/login
Post, edit, delete listings (with images)
Search & filter listings (location, price, room type)
Interest request system (Accept/Reject by owner)
Wishlist (save listings)
Admin dashboard

## Technologies
Frontend: HTML, CSS, Bootstrap
Backend: Node.js, Express.js
Database: MySQL
Auth: JWT + bcrypt
